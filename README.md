# Hameir Laarets Donation Center

A responsive multilingual donation experience for Hameir Laarets. The site
introduces the organization’s Torah and Chesed mission, highlights the current
Elul/Kaparot campaign, lets donors choose a cause and gift amount, preserves
fundraiser attribution, and continues to the organization’s secure checkout.

## Main experience

- English and Spanish donor journeys
- responsive 4K video hero with an accessible poster fallback
- current Elul/Kaparot campaign and donation composer
- ten giving opportunities with cause-specific messaging
- fundraiser and solicitor attribution through URL parameters
- secure-checkout handoff with amount, frequency, language, and tracking data
- responsive, keyboard-friendly interactions and reduced-motion support

## Prerequisites

- Node.js `>=22.13.0`

## Quick Start

```bash
npm install
npm run dev
npm run build
```

This starter does not use `wrangler.jsonc`.

## Useful commands

- `npm run dev`: start local development
- `npm run build`: build the production bundle
- `npm test`: build and run the rendered-page checks

The primary current experience is available at `/v4`.
